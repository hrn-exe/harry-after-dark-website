# Drop your own designs here

The Shop section on the site looks for these exact filenames. Add any of
them and the site swaps it in automatically — no code changes, no rebuild:

| File                  | Product        | Suggested size      |
|------------------------|----------------|----------------------|
| `tee-design.png`       | The tee        | ~800×800px, square   |
| `joggers-design.png`   | The joggers    | ~600×300px, wide     |
| `mug-design.png`       | The mug        | ~800×800px, square   |

**Tips**

- Use a **transparent PNG** (not JPG) so the design sits on the fabric color
  instead of covering it with a white/colored box.
- Keep the design itself roughly centered in the file with a little margin —
  the site scales it to fit the print area but doesn't crop it.
- Any file you *don't* add just keeps showing the current placeholder
  (your avatar + "Something's Wrong") for that product — nothing breaks.
- File names are case-sensitive on GitHub Pages. Match them exactly.

To replace a design later, just overwrite the same filename and push —
browsers cache images, so do a hard refresh (Ctrl+Shift+R) to see the update.
