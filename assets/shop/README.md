# Drop your own product photos here

The Shop section looks for these exact filenames. Add any of them and the
site swaps it in automatically — no code changes, no rebuild:

| File                  | Product        |
|------------------------|----------------|
| `tee-design.png`       | The tee        |
| `joggers-design.png`   | The joggers    |
| `mug-design.png`       | The mug        |

**What to upload:** a full picture of the finished product — a mockup shot
of the actual shirt/joggers/mug with your design already on it (from a
mockup generator like Placeit, Printful, or Canva, or a real product photo).
This image **replaces** the placeholder illustration entirely — it isn't
printed on top of anything, so upload the whole product shot, not just a
logo graphic.

**Tips**

- Any reasonably sized image works (roughly square works best for how the
  stage is laid out, but the site scales it to fit either way without
  cropping).
- A transparent-background PNG looks cleanest against the dark stage, but a
  photo with its own background is fine too — it just shows as a normal
  photo in the frame.
- Any file you *don't* add just keeps showing the current placeholder
  illustration for that product — nothing breaks.
- File names are case-sensitive on GitHub Pages. Match them exactly.

To replace a photo later, just overwrite the same filename and push —
browsers cache images, so do a hard refresh (Ctrl+Shift+R) to see the update.
